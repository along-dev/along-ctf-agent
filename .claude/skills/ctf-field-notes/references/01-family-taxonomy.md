# 01 族分类学（f01..f13）

判族后到本表查主攻路线与同族卡点。族号可叠加，主族定主线、副族定并行侦察。

| 族 | 名称 | 载体特征 | 主攻路线 |
|---|---|---|---|
| f01 | Web-常规 | URL、CMS、目录、API | 01侦察→02扫描→03利用 |
| f02 | Web-认证 | 登录框、SSO、JWT、Session | 认证模型审计 + 弱口令 + 令牌伪造 |
| f03 | Web-文件处理 | 上传、下载、路径穿越、包含 | 11 章：区分读取/写入/越权/执行 |
| f04 | Web-反序列化 | Java/PHP/Node 反序列化点 | gadget 链 + 执行原语 |
| f05 | Web-注入 | SQLi/SSTI/命令注入/XXE | 注入面探测 + 回显/盲注通道 |
| f06 | 主机-外网 | 开放端口、服务、未授权 | 01→02→(05隧道)→07提权 |
| f07 | 主机-内网/域 | 内网IP、AD、域控 | 05隧道→06凭据→08横向 |
| f08 | 链上 | 合约地址、DApp、代币 | onchain-ctf 六步链 |
| f09 | 逆向/Pwn | 二进制、固件、驱动 | 09反编译 + 动态插桩 |
| f10 | 移动 | APK/IPA | apk_analysis 工具链 |
| f11 | 取证 | 磁盘/内存镜像、日志、流量 | 09 保全→提取→解码 |
| f12 | 密码/杂项 | 密文、编码串、隐写 | 09 区分编码/哈希/加密 |
| f13 | LLM/AI | 模型接口、Agent、提示词 | llm-redteam-defense |

## 判族决策树

```
给了什么载体？
├─ URL/域名/IP → 有无登录框？
│   ├─ 有 → f02（叠 f05 若可注入）
│   └─ 无 → f01（叠 f03 若有上传/下载）
├─ 内网IP/域环境 → f07
├─ 合约地址/私钥 → f08
├─ 二进制/固件 → f09
├─ APK/IPA → f10
├─ 镜像/日志/流量 → f11
├─ 密文/编码 → f12
└─ 模型接口/Agent → f13
```

## 叠加示例

- Web 后台 + 链上资产 = f02 + f08（Web 侧找签名者/私钥，链上只读映射）。
- APP + 后端 API = f10 + f01（前端提取端点 → 后端面测）。
- 登录框 + 文件上传 = f02 + f03。
