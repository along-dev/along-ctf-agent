# 12 攻击链思维链（横向贯穿全程，不属于任何单一阶段）

**目标**：把「跑工具」升级成「追线索」。这一章不教具体漏洞，教**看到异常之后下一步做什么**——它是 1–11 章的横向黏合剂，任何阶段发现「有价值信息」时都适用。

> 核心信条：**工具是手脚，思维是大脑。任何人都会跑工具，但不是每个人都知道跑完该干什么。**

## 1. 做侦探，不做记录员

| 记录员（错） | 侦探（对） |
|---|---|
| 扫端口 → 扫目录 → 看结果 → 截图 → 下一个 | 发现 → **追问它能走到哪一步** → 顺着追到底 |

同一个发现，两种人结局不同：

```
发现可访问的 .env
  记录员：记下来，有数据库密码。→ 结束
  侦探：有 DB 密码 → 能否直连？→ 连上能否写文件？→ 写入的点能否 getshell？→ 追到底
```

**渗透不是收集垃圾信息，是把一条线索追到头。**

## 2. 三问法（看到任何有价值信息，强迫自己回答）

1. **它暴露了什么？** 不要停在「这是个 SQL 报错」。追问：报错→DB 类型是 MySQL、版本 5.7、当前用户可能是 root。挖深一层，信息才值钱。
2. **能跟什么串起来？** 单个发现常常不致命，串起来就是攻击链：
   ```
   文件上传点 + 路径穿越点 + 低权限后台
     → 上传图片马 → 路径穿越包含/覆盖 → WebShell
   ```
3. **离目标还有多远？** 终极目标无非三个：**后台权限 / 数据库访问 / 服务器 Shell**。每步都问「这一步让我更靠近哪一个」；哪个都不沾，可能是在浪费时间。

## 3. 别等完美，先动起来

- 信息**永远收集不完**。等端口→等目录→等漏洞→等子域，等你觉得差不多，管理员已经下班。
- 正确节奏：**看到第一条有价值信息就开始利用**。
  - 扫到 Swagger → 立刻翻 API 列表
  - 看到 JWT → 立刻解码看 payload
  - 发现 `.git` → 立刻拖源码
- 即使证明是死路，也只浪费五分钟，而不是等两小时才动手。
- 口诀：**发现有价值 → 立刻深入 → 验证效果 → 继续往前**。别站在原地等。

## 4. 别在同一个坑里转圈

- 一个点死磕是常见病：SQLi 试半小时还在换 Payload；WAF 拦了还硬刚一小时卡在 403。
- 换个思路：**同一目标可能有五个入口，你堵在一个门口两小时，旁边四个门没敲过。**
- 判断标准：某条路连续多次无进展（无新证据、无回显变化、无新报错），就**换入口**，不是加大字典/线程。

## 5. 把经验变成直觉（触发→本能反应）

老手和新手最大的差别不是技术，是**看到什么就知道下一步试什么**。这不是天赋，是每次走完整条推理链重复出来的肌肉记忆。

| 看到什么 | 本能反应 |
|---|---|
| Nginx 报错页 | 记版本号 → 搜对应 CVE / 默认配置 |
| JSON 返回里有 `token` 字段 | 解码看内容 → 试能否重签 / 篡改 |
| 403 但静态图标仍在加载 | 目录**可能真的存在** → 换方法绕（大小写/编码/头） |
| 开发模式报错栈 | 路径泄露 → 拼路径穿越（走 11） |
| 登录页无验证码/无锁定 | 弱口令候选（走 06，先写计划） |
| 首页标题含 bot/panel/dashboard | 疑似后台 → 走 10 测绘语法交叉定位 |

## 与各阶段的衔接

- 01–11 是**动作**；本章是**为什么这么动、动完往哪走**。任何阶段都可以回到本章「三问法」重新决策。
- 当三问法指向「换个入口/追下一跳」时，回到 SKILL.md 的调度表选对应阶段；当指向「离目标更近」时，继续当前阶段并**留证据**。
- 与铁律 #3（分级证明）配合：思维链推动你往前，分级证明约束你**结论只能停在证据支撑的级别**。

## 常见误区

跑完工具就截图存档（记录员）｜发现孤立信息不追问关联｜等信息收全才动手｜一条路堵死还硬刚｜把「下一步该试什么」当成天赋而非可训练的习惯。
