# 04 免杀 & 流量绕过（对抗防护）

**目标**：遇到 WAF/杀软时的对抗方法 + 防守检测视角。重点是理解「安全产品看什么」，不是找黑盒工具。

## 安全产品看三样

1. **静态特征**：哈希、PE 结构、字符串、导入表、熵值、YARA 签名。
2. **动态行为**：进程创建、注册表改、启动项、敏感文件访问、异常网络、进程注入。
3. **网络流量**：URL/参数/UA、请求体长度结构、Base64/高熵、出站域名/频率/规律。

## 检查清单

1. **先判断防护**：有没有 WAF（观察拦截页/响应差异）、有没有杀软/EDR、是不是 CDN 后（看代理头）。
2. **WebShell 流量绕过**：本质是让通信不像异常——但防守方看的是「业务不合理」（冷门路径、固定高熵参数、响应长度随命令变）。攻击方改特征，防守方改行为检测。
3. **WAF 绕过**：利用「浏览器/代理/WAF/后端对同一请求解析不一致」：编码、大小写、重复参数、分块、HTTP 协议差异。核心是**解析差异**，不是魔法。
4. **代理头**：`X-Forwarded-For` `X-Real-IP` `CF-Connecting-IP` `True-Client-IP` 只在来自可信代理时才可信；源站可被绕过 CDN 直连时这些头可伪造。
5. **无文件执行**：不落地≠没证据。看进程树（w3wp→powershell）、命令行、脚本日志、内存、注册表/计划任务持久化。

## 防守视角（CTF 复盘重点）
- 文件被改到静态特征不明显 → 看行为：可疑父子进程、普通进程写启动项、Web 进程建系统命令。
- 内存马/无文件 → 进程注入段、Script Block 日志、异常出站连接。
