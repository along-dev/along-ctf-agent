# 05 广播纪律与回滚清单

`eth_sendRawTransaction` 是写操作，只有满足全部条件才做。

## 广播前（逐项确认）

1. 目标合约 = 用户自有/题面授权/测试网。
2. 金额与 gas 用户确认。
3. 私钥来源合法（题面给/用户自有）。
4. 已用 eth_call 模拟成功。

## 回滚清单

- 交易 nonce 固定，失败可重放/替换（同 nonce 提 gas 替换）。
- 不广播则无任何链上副作用（只读模拟安全）。
- 需要时可先在本地测试网（Ganache/Anvil）跑通再上目标。

## 红线

- 公共主网真实第三方资产：不广播。
- 私钥不落盘、不入日志、不进 git。
